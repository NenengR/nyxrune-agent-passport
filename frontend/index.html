Tentang proyek ini

NyxRune Agent Passport dibangun untuk Binance Agent ID Hackathon. Semua aturan ditegakkan oleh kontrak pintar di BNB Chain, bukan oleh server: hanya pemegang Agent ID yang bisa check-in, mint badge, dan vote. Pemilik kontrak hanya bisa membuat polling, tidak bisa menarik dana, tidak bisa mengubah aturan, dan tidak ada biaya apa pun selain gas.
